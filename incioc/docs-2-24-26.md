# Transformation Steps

In my local copy of the lang4j workshop, I created a new submodule for roq-docs:
`quarkus create app roq-docs -x=io.quarkiverse.roq:quarkus-roq`

> Note: Generated files are left in `site` after MkDocs is run; for our purposes, I am ignoring these generated files. 
> ```sh
> pipenv install;
> pipenv run mkdocs build --clean;
> pipenv run mkdocs serve --livereload; ```

Logs (so far):
```sh
### get code locally
git clone git@github.com:quarkusio/quarkus-workshop-langchain4j.git roq-test-l4j
cd roq-test-l4j
quarkus create app roq-docs -x=io.quarkiverse.roq:quarkus-roq
cd roq-docs/
quarkus ext add quarkus-roq

### testing 
cp ../docs/mkdocs.yml data/
cp ../docs/docs/attributes.yml data/
# make backup of current index
cp content/posts/2024-10-13-the-first-roq/index.md index.md.bak

# copy over the main content for l4j
mkdir content/old && mv index.html content/old/
cp ../docs/docs/index.md content/
cp -r ../docs/docs/section-1 .
cp -r ../docs/docs/section-2 .
```
