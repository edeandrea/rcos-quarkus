## What is Quarkus?
**Quarkus** is a "Supersonic Subatomic" Java framework designed for the modern cloud era. While traditional Java frameworks were built for long-running servers, Quarkus is optimized to run in containers with incredibly fast startup times and very low memory usage.

* **Developer Joy:** You never have to restart your server. You just save your code, refresh your browser, and the changes happen instantly. This makes coding fast and fun.
* **Standard Libraries:** It uses the libraries you likely already know (or will learn in class), such as Hibernate, Jakarta REST, and Kafka.

## Project Stats
* **Established:** The project was established in **2019**.
* **Community:** It is backed by a massive global community, with over **1,000 contributors** from many different companies across the world.

## The Quarkiverse
While the core Quarkus repository contains the most critical extensions, the **Quarkiverse** is the home for everything else. Think of it as the "App Store" or "Plugin Hub" for Quarkus.

* **Explore the Quarkiverse:** https://github.com/quarkiverse/quarkiverse/wiki
