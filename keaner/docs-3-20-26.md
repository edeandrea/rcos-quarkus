# 3/20/26

Today I continued working on migrating the theme, specifically investigating the javascript components that need to be carried over between MkDocs and Roq.

## Light/Dark Toggle

I was able to fix the theme toggle after combing through the copied html and javascript files from the MkDocs build output. I determined that Roq was somehow processing the html slightly differently, such that the "hidden" attribute applied to the toggles in the html source code was preventing the search bar from rendering.

After removing these attributes, the light/dark toggle correctly changed the appearance of the website between the two themes.

## Search Bar

Initially, the search bar was not appearing at all. This is because I was missing some important html components when I copied the search bar over, specifically the "search__overlay" and "search__inner" classes. Adding these tags got the search bar functioning, however the styling is not appearing correctly. The background is a dark translucent color rather than opaque, and the font appears unstyled. At the moment I do not know what is causing this issue.
