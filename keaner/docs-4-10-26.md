# 4/10/26

## Material Theme

I launched the repository for the Quarkus Roq material theme. I cleaned up many of the now-unnecessary built MkDocs files and included only the necessary search and main javascript files. I spoke with Eric about licensing concerns and we determined that the MIT license would be adequate, since that is what MkDocs' material theme was built with.

## Search Plugin

I discovered the [Lunr search plugin](https://quarkus.io/extensions/io.quarkiverse.roq/quarkus-roq-plugin-lunr/) for Roq which will likely be superior to the short search algorithm I had designed for the current Material theme search bar. My plan is to investigate integration of this plugin to replace `roq-search.js`.

## Admonition Support

Admonition support was merged into Qute, which means the next step is to integrate it into the Material theme. Work is already being done to integrate it into Roq's default theme, so I will synthesize their work with the built MkDocs output to add admonition support for Roq Material theme.
