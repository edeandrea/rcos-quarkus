Today I continued working on migrating specific aspects of the theme.


## Sidebar

I noticed that the navigation sidebar was not properly rendering the section titles like MkDocs did. To fix this, I had to modify how IDs were being assigned to the various menu items to prevent any overlap in their hashing. I also had to attach an id attribute to the containe ro fthe sub-sidebar.

## Dynamic Title Bar

The title bar on the MkDocs website will change as the user scrolls down the page, reflecting the tab that they are on. I was able to emulate this with Roq by inserting a Qute template into the `md-header.html` file and searching for the page with the corresponding name.

## Math Equations

Strangely, this is rendered properly on the official Stork website but not on my local clone of the Stork docs.
