# 4/3/26

## Math Expressions

I resolved the math expressions issue by adding the following lines to the default.html file of the Roq template:

```html
<script src="https://polyfill.io/v3/polyfill.min.js?features=es6"></script>
<script src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js"></script>
```

This imports a library called polyfill which automatically parses the math expressions. I also moved away from escaping each bracket individually and instead used Qute's syntax for indicating a "raw" block:

```
{|
$$
Some expression here
$$
|}
```


## Table of Contents

I migrated the table of contents by completing the `toc-sidebar.html` template. All it esseintally does is iterate over the page's headers, slugify the text into a URL, and append `#some-section-here` to automatically navigate the page. Interestingly, I believe this also addressed a visual bug in MkDocs, where the incorrect section would be highlighted when jumping between sections.
