# 2/12/26

I succesfully migrated the MkDoc landing page to Roq. Right now, I am using the default template that came with the Roq Demo, but in the future I will attempt to recreate the MkDocs "look and feel." Using this template required me to add front matter to the overview page, which contained some unnecessary information that I will remove later. I noticed a few key differences:

1. MkDocs defines variables in mkdocs.yml, whereas Roq defines them in yml files in the data/ directory. I had to move the variable definitions to a new yml file, which I called extra.yml for now.
2. Inline code blocks are not supported in Roq, or have alternative syntax. E.g. `this` renders as a code block in MkDoc, but not in Roq.
3. (More investigation required) The images on the Roq website appeared considerably larger than on MkDoc.
4. (More investigation required) The table of contents is not shown on the right side, which is likely related to the theme.
